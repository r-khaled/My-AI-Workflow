# Prompt 5 — Operate and Improve

Review the installed workflow using real execution evidence.

Inputs:

- completed blueprint;
- approved design;
- implementation and validation reports;
- selected task summaries;
- operator feedback;
- usage, latency, failure, and repair-loop observations.

Do not modify configuration yet.

For each agent, skill, hook, integration, and automation:

1. identify scenarios that invoked it;
2. compare expected and observed inputs and outputs;
3. identify false or missed triggers, overlap, and unused components;
4. assess quality, speed, repeatability, and context impact;
5. identify unnecessary model effort or delegation;
6. identify safety or permission friction;
7. recommend keep, tune, merge, disable, or remove;
8. propose the smallest reversible change and validation plan.

Also review global versus project placement, routing, concurrency, ownership,
skill evals, guidance, checkpoints, and workflows now stable enough for
controlled automation.

Stop after the proposal. Apply changes only after approval.
