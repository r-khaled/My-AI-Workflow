# My AI Workflow

A collection of reusable AI-engineering resources for software development,
DevOps, infrastructure, and agent-assisted delivery.

## Toolkits

- [Codex Setup Blueprint](./codex-setup/README.md): discover, design, build,
  validate, and improve a personalized agent workflow across multiple projects.
- `copilot/`: existing Copilot-oriented agents, skills, and reference material.

Each toolkit has its own README and safety boundaries. Do not commit secrets,
credentials, production data, or authentication state.
